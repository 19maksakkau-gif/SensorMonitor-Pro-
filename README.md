📡 SensorMonitor Pro — монитор датчиков (акселерометр, гироскоп, компас)
Интерактивный инструмент для отображения данных с акселерометра, гироскопа и магнитометра в реальном времени.
Поддерживает фильтрацию, калибровку, визуализацию и экспорт данных.
Реализован на 7 языках программирования для демонстрации кроссплатформенного доступа к сенсорам.

🧠 Концепция
SensorMonitor Pro — это утилита для мониторинга данных с акселерометра (ускорение), гироскопа (угловая скорость) и компаса (магнитное поле). Она позволяет:

✅ Отображать значения по трём осям (X, Y, Z) для каждого датчика.

✅ Визуализировать данные в виде графиков (в некоторых версиях).

✅ Применять фильтры (например, комплиментарный фильтр для получения угла наклона).

✅ Калибровать датчики (установка нуля).

✅ Сохранять логи в CSV/JSON.

✅ Настраивать частоту обновления.

✅ Работать как в консольном, так и в GUI-режиме (в некоторых версиях).

✅ Поддерживать симуляцию для тестирования без реального оборудования.

🚀 Как запустить
Каждая версия использует соответствующие системные или эмуляционные библиотеки. Для реальных датчиков требуется поддержка на устройстве.

Python
bash
pip install numpy matplotlib  # для графиков
python sensor_monitor_python.py
C++
bash
# Для Linux требуется libsensors-dev (опционально)
g++ -std=c++17 sensor_monitor.cpp -o sensormonitor
./sensormonitor
Java
bash
javac SensorMonitorJava.java && java SensorMonitorJava
C# (.NET Core)
bash
dotnet run
Go
bash
go run sensor_monitor.go
Rust
bash
cargo build --release && ./target/release/sensor_monitor_rs
JavaScript (Node.js)
bash
node sensor_monitor.js
